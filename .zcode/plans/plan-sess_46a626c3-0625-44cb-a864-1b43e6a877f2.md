## Implementation Plan for Missing UI Progress Component

**Background**
- Vite build fails because `src/components/ui/progress` cannot be resolved (error shown in `ActivityMonitor.tsx`). The UI components directory lacks a `progress.tsx` file.
- `ActivityMonitor` expects a `Progress` component that receives a numeric `value` prop (percentage) and optional `className` for styling.

**Findings**
1. `src/components/ui` contains Shadcn‑style components (`card.tsx`, `button.tsx`, etc.) but no `progress.tsx`.
2. All UI components import the `cn` helper from `@/lib/utils` and follow a simple functional‑component pattern.
3. Vite's alias `@` points to the `src` folder (see `vite.config.ts`), so the import path `@/components/ui/progress` will resolve once the file exists.

**Implementation Steps**
1. **Create the Progress component** at `frontend/src/components/ui/progress.tsx`:
   ```tsx
   import * as React from "react";
   import { cn } from "@/lib/utils";

   export interface ProgressProps extends React.HTMLAttributes<HTMLDivElement> {
     /** Completion percentage (0‑100). */
     value?: number;
     /** Maximum value, default 100. */
     max?: number;
   }

   export const Progress = ({
     className,
     value = 0,
     max = 100,
     ...props
   }: ProgressProps) => {
     const percentage = Math.min(Math.max(value / max, 0), 1) * 100;
     return (
       <div
         className={cn(
           "relative w-full overflow-hidden rounded-full bg-primary/10",
           className
         )}
         {...props}
       >
         <div
           className="h-full bg-primary transition-all"
           style={{ width: `${percentage}%` }}
         />
       </div>
     );
   };
   ```
   - Mirrors the design of other UI components.
   - Uses `cn` for Tailwind class merging.
   - Provides sensible defaults and clamps the percentage.
2. **Run lint and type‑check** (`npm run lint` or the project's lint script) to verify Tailwind classes and TypeScript compilation.
3. **Execute frontend tests** (`npm run test` or equivalent) to ensure no regression.
4. **Verify the Vite build** (`npm run dev` or `npm run build`). The import error should disappear and `ActivityMonitor` should render a functional progress bar.
5. **Commit the change**:
   ```bash
   git add frontend/src/components/ui/progress.tsx
   git commit -m "feat(ui): add Progress component for admin dashboard"
   git push
   ```
