# Mathématiques — Équations

## equations
Une équation est une égalité comportant une ou plusieurs inconnues. Résoudre une équation consiste à trouver toutes les valeurs des inconnues qui rendent l'égalité vraie. Le degré d'une équation polynomiale est l'exposant le plus élevé de l'inconnue. Deux principes gouvernent la résolution : on peut ajouter ou soustraire une même quantité aux deux membres, multiplier ou diviser les deux membres par un même nombre non nul. L'équilibre de l'égalité doit être préservé à chaque étape.

## premier-degre
Une équation du premier degré s'écrit ax + b = 0 avec a non nul ; sa solution unique est x = -b/a. Méthode : isoler progressivement l'inconnue en déplaçant les termes (changement de membre = changement de signe), puis diviser par le coefficient de l'inconnue. Vérifier la solution en la reportant dans l'équation initiale est une habitude essentielle. Si a = 0 et b ≠ 0, l'équation n'a aucune solution ; si a = 0 et b = 0, tout x est solution.

## inconnue
L'inconnue est la quantité cherchée, traditionnellement notée x. Choisir l'inconnue est la première étape de la mise en équation d'un problème : identifier ce qu'on cherche, le nommer, puis traduire les données de l'énoncé en relations mathématiques. Une bonne mise en équation vaut plus que le calcul lui-même : elle transforme un problème concret en un problème algébrique standard.

## verification
Vérifier une solution consiste à la substituer dans l'équation de départ pour confirmer l'égalité. Cette étape détecte les erreurs de calcul (signes, fractions, distribution). Dans un problème concret, on vérifie aussi la cohérence avec l'énoncé : une longueur négative ou un effectif non entier sont des signaux d'erreur. Le réflexe de vérification systématique distingue un calcul juste d'une réponse fiable.
